# Naveen Yadav - Personal Portfolio Website

A personal portfolio website for **Naveen Yadav**, Business Analyst, Project Coordinator & Digital Marketing Strategist (MSc Information Systems and Business Analysis, Aston University).

Built with **React 19**, **Vite**, **Tailwind CSS v4**, **Framer Motion**, and **Web3Forms**.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The site will run at `http://localhost:5173`.

### 3. Build for Production
```bash
npm run build
```
The compiled, production-ready static assets will be created in the `dist/` directory.
